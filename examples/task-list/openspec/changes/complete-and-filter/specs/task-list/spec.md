## ADDED Requirements

### Requirement: REQ-F2-01 完成任务

用户 MUST 能勾选任务并在刷新后看到保存的完成状态。

#### Scenario: AC-F2-01 只完成选中的任务

- **WHEN** 清单有两条未完成任务，用户勾选其中一条并刷新
- **THEN** 该任务显示为已完成，另一条仍未完成

### Requirement: REQ-F2-02 按状态筛选

页面 MUST 提供全部、未完成、已完成三个视图。

#### Scenario: AC-F2-02 在混合清单中切换视图

- **WHEN** 清单同时有已完成和未完成任务，用户依次选择已完成、未完成和全部
- **THEN** 前两个视图各自只展示对应任务，全部视图恢复完整清单
